# RespiRA

Website Quarto do projeto RespiRA, um ensaio clínico randomizado que avalia uma aplicação móvel de autogestão da asma em adultos com asma moderada persistente em cuidados de saúde primários.

O repositório inclui:

- protocolo do ensaio clínico;
- diagramas do estudo e da aplicação;
- eCRF e análise do eCRF;
- dicionário de dados REDCap;
- material de suporte à Investigator's Meeting;
- protótipo Figma da aplicação;
- análise preliminar dos dados piloto.
